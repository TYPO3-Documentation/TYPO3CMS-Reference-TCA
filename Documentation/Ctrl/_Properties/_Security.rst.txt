..  confval:: security
    :name: ctrl-security
    :TCA path: $GLOBALS['TCA'][$table]['ctrl']['security']
    :type: array
    :Scope: Display

    Array of sub-properties. This is used, for example, in the Core for the
    `sys_file` table:

    ..  code-block:: php
        :caption: EXT:core/Configuration/TCA/sys_file.php (excerpt)

        return [
            'ctrl' => [
                // ...
                'security' => [
                    'ignoreWebMountRestriction' => true,
                    'ignoreRootLevelRestriction' => true,
                ],
                // ...
            ],
        ];

    And `ignorePageTypeRestriction` is used for the `sys_note` table:

    ..  code-block:: php
        :caption: EXT:sys_note/Configuration/TCA/sys_note.php (excerpt)

        return [
            'ctrl' => [
                // ...
                'security' => [
                    'ignorePageTypeRestriction' => true,
                ],
                // ...
            ],
        ];

    You can also use it in an override file:

    ..  code-block:: php
        :caption: EXT:my_extension/Configuration/TCA/Overrides/tx_myextension_mytable.php

        $GLOBALS['TCA']['tx_myextension_mytable']['ctrl']['security']['ignoreWebMountRestriction'] = true;
        $GLOBALS['TCA']['tx_myextension_mytable']['ctrl']['security']['ignoreRootLevelRestriction'] = true;
        $GLOBALS['TCA']['tx_myextension_mytable']['ctrl']['security']['ignorePageTypeRestriction'] = true;

    ignoreWebMountRestriction
        Allows users to access records that are not in their defined web-mount,
        thus bypassing this restriction.

    ignoreRootLevelRestriction
        Allows non-admin users to access records that are on the root-level
        (page ID `0`), thus bypassing this usual restriction.

    ignorePageTypeRestriction
        Allows to use a TCA table on any kind of page doktype unless a doktype
        has a restriction set in the
        :php-short:`\TYPO3\CMS\Core\DataHandling\PageDoktypeRegistry` API class.
