.. _ctrl-reference-type:

.. confval:: type
   :name: ctrl-type
   :TCA path: $GLOBALS['TCA'][$table]['ctrl']['type']
   :type: string (field name, or relation_field:foreign_type_field)
   :Scope: Display / Proc.

   Field name, which defines the "record type".

   The value of this field determines which one of the :ref:`types <types>`
   configurations are used for displaying the fields in the FormEngine. It
   will probably also affect how the record is used in the context where it belongs.

   The most widely known usage of this feature is the case of *Content Elements*
   where the :guilabel:`Type:` selector is defined as the "CType" field and when you
   change that selector you will also get another rendering of the form:

   ..  figure:: /Images/Conference/CtrlTypeContentElement.png
       :alt: The type field of a content element
       :class: with-shadow

       The type field of a content element

   It is used for example by the "doktype" field in the "pages" table.

   On changing the value of the field defined in `type` the user gets prompted
   to reload the record.

   ..  figure:: /Images/Conference/CtrlTypeChangeModal.png
       :alt: Changing the type asks to save the record and reload the form
       :class: with-shadow

       Changing the type asks to save the record and reload the form

   Only one type field can be defined. If you need to reload the record on
   changing another field, see
   :ref:`property onchange <columns-properties-onchange>`.

   It is also possible to make the type depend on the value of a related record,
   for example to switch using the type field of a
   foreign table. The syntax is `relation_field:foreign_type_field`.
   For example the `sys_file_metadata` table takes its type from the
   `sys_file` table.

The type stored in a field

keynote. The field `talk_type` stores which one it is, so the `ctrl` section

..  _ctrl-reference-type-foreign-table-field:

Type in relation to a foreign table's field
-------------------------------------------

..  figure:: /Images/Conference/CtrlTypeForeign.png
    :alt: Two partnerships of a conference, each with other fields
    :class: with-shadow

    The partnership with an online conference shows other fields

A partnership relates a conference to a partner conference. The format of
the partner conference decides which fields the partnership shows. An
on-site partner conference gives a discount. An online partner conference
shares its live stream.

The `select` field `partner` points to the partner conference. The `type`
in the `ctrl` section names this field and the field `event_format` of the
conference, separated by a colon:

..  literalinclude:: /CodeSnippets/my_extension/Configuration/TCA/Overrides/910-tx_myextension_partnership-type.php
    :caption: EXT:my_extension/Configuration/TCA/Overrides/910-tx_myextension_partnership-type.php
    :emphasize-lines: 10,13,27-29

The field that points to the other record must be of the type `select`,
`category`, or `group`. A `group` field takes the first table of its
`allowed` list.

The value `online` has its own entry in the `types` section. On-site and
hybrid partner conferences have no entry of their own, so these
partnerships use the type `0`. When an editor selects another partner
conference, the form reloads and shows the fields of the new type.
