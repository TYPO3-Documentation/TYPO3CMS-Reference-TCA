..  _ctrl-reference-adminonly:

..  confval:: adminOnly
    :name: ctrl-adminOnly
    :TCA path: $GLOBALS['TCA'][$table]['ctrl']['adminOnly']
    :type: boolean
    :Scope: Display / Proc.

    Records can be changed  *only* by "admin"-users (having the "admin" flag set).

    ..  rubric:: Example: Table `tx_myextension_mytable` is only editable by admin users:

    ..  code-block:: php
        :caption: EXT:my_extension/Configuration/TCA/tx_myextension_mytable.php

        'ctrl' => [
            'adminOnly' => 1,
            ...
        ],
