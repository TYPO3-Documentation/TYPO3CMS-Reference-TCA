..  _ctrl-reference-previewrenderer:

..  confval:: previewRenderer
    :name: ctrl-previewRenderer
    :TCA path: $GLOBALS['TCA'][$table]['ctrl']['previewRenderer']
    :type: string (class name)
    :Scope: Display

    Configures a backend preview for a content element.

    Have also a look at :ref:`configure a custom backend preview <t3coreapi:ConfigureCE-Preview>` for more details.

    Use :confval:`property previewRenderer of section types <types-previewRenderer>`
    to configure the preview for a certain type only.

    The :guilabel:`Content > Layout` module renders the previews, so the
    option only takes effect in the table `tt_content`. The Core sets the
    standard preview renderer for all content elements:

    ..  code-block:: php
        :caption: EXT:frontend/Configuration/TCA/tt_content.php (excerpt)

        'ctrl' => [
          'previewRenderer' => \TYPO3\CMS\Backend\Preview\StandardContentPreviewRenderer::class,
        ],

    The conference teaser of the example extension has a
    :ref:`preview renderer of its own <types-example-previewrenderer>`.
