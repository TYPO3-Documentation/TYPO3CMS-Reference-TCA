..  _columns-properties-label:

..  confval:: label
    :name: columns-label
    :TCA path: $GLOBALS['TCA'][$table]['columns'][$field]['label']
    :required: true
    :type: plain text label or `label reference <https://docs.typo3.org/permalink/t3coreapi:label-reference>`_
    :Scope: Display
    :Examples: :ref:`the basic input field example <columns-example-basic>`

    The name of the field as shown in the form:

    ..  figure:: /Images/Conference/ColumnsBasicField.png
        :alt: The label of the title field, followed by the field name in debug mode
        :class: with-shadow

        The label of the title field, followed by the field name in debug mode

    ..  note::
        Labels can be overridden in the
        :ref:`types definition <types-properties-showitem>` and the
        :ref:`palettes definition <palettes-properties-showitem>`. They can also
        be overridden by the page TSconfig property
        :ref:`label <t3tsref:tceform_label>`.
