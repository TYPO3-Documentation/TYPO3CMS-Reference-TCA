..  _columns-link-properties-appearance:

..  confval:: appearance
    :name: link-appearance
    :TCA path: $GLOBALS['TCA'][$table]['columns'][$field]['config']['appearance']
    :type: array
    :Scope: Display

    Has information about the appearance, namely:

    ..  confval:: allowedOptions
        :name: link-appearance-allowedOptions
        :TCA path: $GLOBALS['TCA'][$table]['columns'][$field]['config']['appearance']['allowedOptions']
        :type: array

        Display certain options in the link browser.
        To allow all options in the Link Browser, skip this configuration or set
        it to :php:`['*']`. To deny all options in the Link Browser, set this
        configuration to :php:`[]` (empty :php:`array`).

        class
            Custom CSS classes for the link

        params
            Additional link parameters

        target
            Either empty, `_top` or `_blank`

        title
            The `title` attribute of the link

        rel
            The link relationship.

            ..  versionchanged:: 14.2
                No longer limited to RTE-enabled fields.

            For RTE-enabled fields,
            `buttons.link.relAttribute.enabled <https://docs.typo3.org/permalink/t3tsref:buttons-link-relattribute-enabled>`_,
            must be enabled.

        ..  code-block:: php

            'appearance' => [
              // Display only 'class' and 'params'
              'allowedOptions' => ['class', 'params'],
            ],

        ..  code-block:: php

            'appearance' => [
              // Allow all options (or skip this option)
              'allowedOptions' => ['*'],
            ],

        ..  literalinclude:: /CodeSnippets/my_extension/Configuration/TCA/Overrides/240-tx_myextension_talk-recording.php
            :caption: EXT:my_extension/Configuration/TCA/Overrides/240-tx_myextension_talk-recording.php
            :emphasize-lines: 14

        For custom email links, the options can be restricted:

        body
            The body of an email can be pre-filled.

        cc
            The "cc" field can be pre-filled.

        bcc:
            The "bcc" field can be pre-filled.

        subject:
            The subject of an email can be pre-filled.

        ..  code-block:: php

            'allowedTypes' => ['email'],
            'appearance' => [
              'allowedOptions' => ['body', 'cc'],
            ],

    ..  confval:: allowedFileExtensions
        :name: link-appearance-allowedFileExtensions
        :TCA path: $GLOBALS['TCA'][$table]['columns'][$field]['config']['appearance']['allowedFileExtensions']
        :type: array

        An array of allowed file extensions. To allow all extensions, skip this
        configuration or set it to :php:`['*']`. It's not possible to deny all
        extensions.

        ..  code-block:: php

            'appearance' => [
              // Allow only jpg and png file extensions
              'allowedFileExtensions' => ['jpg', 'png'],
            ],

        ..  code-block:: php

            'appearance' => [
              // Allow all file extensions (or skip this option)
              'allowedFileExtensions' => ['*'],
            ],

    ..  confval:: browserTitle
        :name: link-appearance-browserTitle
        :TCA path: $GLOBALS['TCA'][$table]['columns'][$field]['config']['appearance']['browserTitle']
        :type: string, LLL

        Allows to set a different `title` attribute for the Link Browser icon, defaults to `Link`.

        ..  literalinclude:: /CodeSnippets/my_extension/Configuration/TCA/Overrides/118-tx_myextension_conference-ticket_link.php
            :caption: EXT:my_extension/Configuration/TCA/Overrides/118-tx_myextension_conference-ticket_link.php
            :emphasize-lines: 20

        ..  code-block:: php

            'appearance' => [
              // Or a plain string
              'browserTitle' => 'Link to the tickets',
            ],

    ..  confval:: enableBrowser
        :name: link-appearance-enableBrowser
        :TCA path: $GLOBALS['TCA'][$table]['columns'][$field]['config']['appearance']['enableBrowser']
        :type: boolean

        The Link Browser is enabled by default.
        To disable the Link Browser altogether, set this option to :php:`false`.
