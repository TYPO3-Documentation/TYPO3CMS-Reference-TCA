..  _columns-inline-properties-foreign-match-fields:

..  confval:: foreign_match_fields
    :name: inline-foreign-match-fields
    :TCA path: $GLOBALS['TCA'][$table]['columns'][$field]['config']['foreign_match_fields']
    :type: array
    :Scope: Proc.

    Array of field-value pairs to both insert and match against when writing/reading IRRE relations. Using the match
    fields, it is possible to re-use the same child table in more than one field of the parent table by using a match
    field with different values for each of the use cases.

..  rubric:: Examples

A conference has two fields of type "inline", `registrations` and
`waiting_list`. Both contain registrations. The field `status` of the
registration, which the form does not show, keeps them apart:

If the match field is made editable, for instance as a select drop-down of two values, the relation would
switch between the two parent fields after change and save. If an editor changed the status of a
registration from "waiting" to "confirmed", the registration would move from the waiting list to the
registrations on save.
