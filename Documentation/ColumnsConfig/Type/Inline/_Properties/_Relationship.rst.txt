..  _columns-inline-properties-relationship:

..  confval:: relationship
    :name: inline-relationship
    :TCA path: $GLOBALS['TCA'][$table]['columns'][$field]['config']['relationship']
    :type: string
    :Scope: Proc.
    :added: 13.3

    Defines whether the field holds one child record or several. This
    decides which value a
    `Record object <https://docs.typo3.org/permalink/t3coreapi:database-record-objects>`_
    provides for this field, for example in a Fluid template.

    `oneToOne`, `manyToOne`
        The field provides a single
        :php-short:`\TYPO3\CMS\Core\Domain\Record` object, or :php:`null` if
        there is no child record. :confval:`maxitems <inline-maxitems>` is
        set to `1` automatically, overriding any other value.

    `oneToMany`
        The field provides a
        :php-short:`\TYPO3\CMS\Core\Collection\LazyRecordCollection` of
        :php-short:`\TYPO3\CMS\Core\Domain\Record` objects.

    If `relationship` is not set, the field also provides a collection. So
    does a field with :confval:`MM <inline-mm>`, whatever `relationship`
    says. Any other value, including `manyToMany`, throws an exception
    unless `MM` is set.

    `maxitems` does not change the result the other way round: a field
    without `relationship` still provides a collection, even if `maxitems`
    is `1`.
