..  confval:: slider
    :name: number-slider
    :TCA path: $GLOBALS['TCA'][$table]['columns'][$field]['config']['slider']
    :type: array
    :Scope: Display

    Render a value slider next to the field.

    It is advised to also define a :ref:`range <columns-number-properties-range>`
    property, otherwise the slider will go from 0 to 10000. Note the range can
    be negative if needed. Available keys:

    step (integer / float)
        Set the step size the slider will use. For floating point values this can itself be a floating point value.

    width (integer, pixels)
        Define the width of the slider.

..  rubric:: Example: A duration between 5 and 240 minutes in steps of 5

..  literalinclude:: /CodeSnippets/my_extension/Configuration/TCA/Overrides/220-tx_myextension_talk-duration.php
    :caption: EXT:my_extension/Configuration/TCA/Overrides/220-tx_myextension_talk-duration.php
    :emphasize-lines: 16

..  rubric:: Example: Slider without a range, between 0 and 10 000

..  code-block:: php

    'slider' => [
      'step' => 1,
    ],

..  rubric:: Example: Decimal slider between 0 and 1

..  code-block:: php

    'scale' => 2,
    'range' => [
      'lower' => 0,
      'upper' => 1,
    ],
    'slider' => [
      'step' => 0.1,
    ],
