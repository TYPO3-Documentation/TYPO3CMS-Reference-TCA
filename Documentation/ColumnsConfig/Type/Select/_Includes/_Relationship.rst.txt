..  versionadded:: 13.3

Defines whether the field holds one related record or several, if it
relates to records through `foreign_table`. This decides which value a
`Record object <https://docs.typo3.org/permalink/t3coreapi:database-record-objects>`_
provides for this field, for example in a Fluid template.

`oneToOne`, `manyToOne`
    The field provides a single
    :php-short:`\TYPO3\CMS\Core\Domain\Record` object, or :php:`null` if
    no record is selected. `maxitems` is set to `1` automatically,
    overriding any other value.

`oneToMany`
    The field provides a
    :php-short:`\TYPO3\CMS\Core\Collection\LazyRecordCollection` of
    :php-short:`\TYPO3\CMS\Core\Domain\Record` objects.

A field with `MM` always provides a collection, whatever `relationship`
says. Any other value, including `manyToMany`, throws an exception unless
`MM` is set.

`maxitems` does not change the result the other way round: a field with
`oneToMany` still provides a collection, even if `maxitems` is `1`.

A select field without `foreign_table` has no relation. It provides an
array of the selected values, or the single value for
`renderType => 'selectSingle'`.
