..  confval:: addRecord
    :name: select-byside-fieldControl-addRecord
    :TCA path: $GLOBALS['TCA'][$table]['columns'][$field]['config']['fieldControl']['addRecord']
    :type: array
    :Scope: Display
    :Types: :ref:`group <columns-group>`

    Button control that adds a related record. Leaves the current
    view and opens a new form to add a new record. On 'Save and close', the
    record is selected.

    ..  note::
        The add record control is disabled by default, enable it with
        :confval:`select-byside-fieldControl-addRecord-disabled`.

    ..  confval:: disabled
        :name: select-byside-fieldControl-addRecord-disabled
        :TCA path: $GLOBALS['TCA'][$table]['columns'][$field]['config']['fieldControl']['addRecord']['disabled']
        :type: boolean
        :Scope: Display
        :default: true

        Disables the field control. Needs to be set to :php:`false` to enable the
        :guilabel:`Create new` button

    ..  confval:: options
        :name: select-byside-fieldControl-addRecord-options
        :TCA path: $GLOBALS['TCA'][$table]['columns'][$field]['config']['fieldControl']['addRecord']['options']

        ..  confval:: pid
            :name: select-byside-fieldControl-addRecord-options-pid
            :TCA path: $GLOBALS['TCA'][$table]['columns'][$field]['config']['fieldControl']['addRecord']['options']['pid']
            :type: string
            :Scope: Display
            :Values: marker or an integer
            :default: ###CURRENT_PID###

            The pid of the new record, as a number or as one of these
            markers:

            `###CURRENT_PID###`
                The pid of the record that is edited.

            `###THIS_UID###`
                The uid of the record that is edited.

            `###SITEROOT###`
                The uid of the root page of the site that the record
                belongs to.

            `###PAGE_TSCONFIG_ID###`
                The value of
                `TCEFORM.<table>.<field>.PAGE_TSCONFIG_ID <https://docs.typo3.org/permalink/t3tsref:tceform-page-tsconfig-id>`_
                in the page TSconfig.

            The control resolves no other marker, and an unknown marker
            becomes the pid 0. The markers of
            `foreign_table_where <https://docs.typo3.org/permalink/t3tca:confval-select-byside-foreign-table-where>`_
            are a different set. `###SITE:<KEY>.<SUBKEY>###` is one of them:
            it resolves in a :sql:`WHERE` clause, not here.

            Without this option the record is created on the current pid.
            If the table is allowed on the root level only, the record is
            created with the pid 0.

        ..  confval:: title
            :name: select-byside-fieldControl-addRecord-options-title
            :TCA path: $GLOBALS['TCA'][$table]['columns'][$field]['config']['fieldControl']['addRecord']['options']['title']
            :type: string
            :Values: plain text label or `label reference <https://docs.typo3.org/permalink/t3coreapi:label-reference>`_
            :default: `LLL:core.core:labels.createNew`

            Sets the 'title' attribute of the popup icon.

        ..  confval:: setValue
            :name: select-byside-fieldControl-addRecord-options-setValue
            :TCA path: $GLOBALS['TCA'][$table]['columns'][$field]['config']['fieldControl']['addRecord']['options']['setValue']
            :type: string
            :Values: string
            :default: append

            Can be one of 'set', 'prepend' or 'append'. 'Set' substitutes the
            new record for the selected record, 'prepend' adds the new record to the top of
            the list and 'append' adds it at the bottom.
