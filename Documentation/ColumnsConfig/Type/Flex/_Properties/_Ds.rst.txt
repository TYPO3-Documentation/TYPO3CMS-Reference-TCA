..  _columns-flex-properties-ds:

..  confval:: ds
    :name: flex-ds
    :TCA path: $GLOBALS['TCA'][$table]['columns'][$field]['config']['ds']
    :type: string
    :Scope: Display / Proc.

    ..  versionchanged:: 14.0
        :changelog: breaking-107047-1751982363

        Multiple entries are no longer supported. Instead use
         `columnsOverrides  <https://docs.typo3.org/permalink/t3tca:confval-types-columnsoverrides>`_.

        The changelog entry describes the migration.

    This field can either contain a file reference to the file containing
    the FlexForm's XML (`'ds' => 'FILE:EXT:news/Configuration/FlexForm.xml'`)
    or contain the XML content directly (`'ds' => '<T3DataStructure>...'`).

    ..  rubric:: Example with XML in external file

    ..  code-block:: php
        :caption: EXT:my_extension/Configuration/TCA/tx_myextension_mytable.php (excerpt)

        'config' => [
            'type' => 'flex',
            'ds' => 'FILE:EXT:my_extension/Configuration/FlexForms/ConferenceList.xml',
        ],

    The included file:

    ..  literalinclude:: /CodeSnippets/my_extension/Configuration/FlexForms/ConferenceList.xml
        :caption: EXT:my_extension/Configuration/FlexForms/ConferenceList.xml
        :visible-lines: 1-29, 113-115, 157-158

    ..  rubric:: Example with XML directly entered

    ..  code-block:: php
        :caption: EXT:my_extension/Configuration/TCA/tx_myextension_mytable.php (excerpt)

        'config' => [
            'type' => 'flex',
            'ds' => '
                <T3DataStructure>
                    <ROOT>
                        <type>array</type>
                        <el>
                            <settings.limit>
                                <label>Maximum number of conferences</label>
                                <config>
                                    <type>number</type>
                                </config>
                            </settings.limit>
                        </el>
                    </ROOT>
                </T3DataStructure>
            ',
        ],
