======
format
======

..  confval:: format
    :name: text-format
    :TCA path: $GLOBALS['TCA'][$table]['columns'][$field]['config']['format']
    :type: string (keyword)
    :Scope: Display

    The value specifies the language the code editor should handle. Allowed
    values:

    *   `css`
    *   `html`
    *   `javascript`
    *   `json`
    *   `php`
    *   `sql`
    *   `typoscript`
    *   `xml`

    See also :ref:`Code highlighting with the code editor <tca-example-codeeditor-1>`.
