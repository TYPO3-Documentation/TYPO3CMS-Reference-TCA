..  _columns-text-properties-valuepicker:

..  confval:: valuePicker
    :name: text-valuePicker
    :TCA path: $GLOBALS['TCA'][$table]['columns'][$field]['config']['valuePicker']
    :type: array
    :Scope: Display
    :changed: 14.0 breaking-107677-1760339783

    Renders a select box with prepared texts next to the field. When the
    editor selects an item, its value replaces the current text of the field.

    ..  versionchanged:: 14.0
        The modes `append` and `prepend` were removed, and TYPO3 ignores the
        option `mode`. TYPO3 migrates items with numeric keys to the keys
        `label` and `value`.

    items (array)
        A list of selectable items. Each item is an associative array:
        :php:`['label' => 'Shown label', 'value' => 'The prepared text.']`.
        The label can be plain text or a
        `label reference <https://docs.typo3.org/permalink/t3coreapi:label-reference>`_.

..  rubric:: Example: Prepared answers of the organizers

The organizers answer comments with a reply. A reply offers prepared
answers, a normal comment does not. Therefore the inline field `reply`
sets the value picker with
