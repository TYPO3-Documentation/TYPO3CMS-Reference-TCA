..  confval:: cols
    :name: text-cols
    :TCA path: $GLOBALS['TCA'][$table]['columns'][$field]['config']['cols']
    :type: integer
    :Scope: Display

    Abstract value for the width of the :html:`<textarea>` field. To set
    the textarea to the full width of the form area, use the value 50. Default is 30.

    Does not apply to RTE fields.
