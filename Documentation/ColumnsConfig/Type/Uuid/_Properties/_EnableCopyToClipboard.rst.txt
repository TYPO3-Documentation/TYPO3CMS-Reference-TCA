
..  _columns-uuid-properties-enablecopytoclipboard:

..  confval:: enableCopyToClipboard
    :name: uuid-enableCopyToClipboard
    :TCA path: $GLOBALS['TCA'][$table]['columns'][$field]['config']['enableCopyToClipboard']
    :type: boolean
    :default: true
    :Scope: Display
    :deprecated: 15.0 deprecation-110865-1790803661

    Shows a button next to the input field. The button copies the UUID to
    the clipboard of the operating system.

    Use :ref:`appearance.copyToClipboard <confval-uuid-appearance-copytoclipboard>`
    instead. The TCA migration converts this option, also in
    `columnsOverrides` and in FlexForm fields.

    The page TSconfig `TCEFORM.<table>.<field>.config.enableCopyToClipboard`
    works until TYPO3 v16.0. Use
    `TCEFORM.<table>.<field>.config.appearance.copyToClipboard` instead.
