    Properties that only apply to how the field is displayed in the backend.

    ..  confval:: prefix
        :name: slug-appearance-prefix
        :Path: $GLOBALS['TCA'][$table]['columns'][$field]['config']['appearance']['prefix']
        :type: userFunction
        :Scope: Display

        ..  versionadded:: 14.2
            The user function now receives the full TCA field configuration
            (`config`) and the field name (`fieldName`) as additional
            parameters.

        Provides a string that is displayed in front of the input field.
        The URL of the site is set by default if nothing has been defined.

        Assign a user function. It receives two arguments:

        *   The first argument is the parameters array containing

            *   `site` - The current site object
            *   `languageId` - The current language ID (int)
            *   `table` - The table name (string)
            *   `row` - The current record data (array)
            *   `fieldName` - The name of the slug field (string)
            *   `config` - The full TCA configuration array of the slug field

        *   The second argument is the reference object
            :php-short:`\TYPO3\CMS\Backend\Form\FormDataProvider\TcaSlug`.

        The user function should return the string which is then used for display
        purposes.
