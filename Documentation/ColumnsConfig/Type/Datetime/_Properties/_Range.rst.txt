..  confval:: range
    :name: datetime-range
    :TCA path: $GLOBALS['TCA'][$table]['columns'][$field]['config']['range']
    :type: array
    :Scope: Proc.

    An array which defines an integer range within which the value must be. Keys:

    lower
        Defines the earliest date.

    upper
        Defines the latest date.

    It is allowed to specify only one or both of them.

    In this example, the earliest end date of a conference is the first day
    of 2020, and the latest end date is the last day of 2030:

    ..  literalinclude:: /CodeSnippets/my_extension/Configuration/TCA/Overrides/113-tx_myextension_conference-end_date.php
        :caption: EXT:my_extension/Configuration/TCA/Overrides/113-tx_myextension_conference-end_date.php
        :emphasize-lines: 15-18

    ..  note::
        As the TCA is cached, it is not possible to set dynamic values such as
        :php:`now()`.
