..  confval:: placeholder
    :name: datetime-placeholder
    :TCA path: $GLOBALS['TCA'][$table]['columns'][$field]['config']['placeholder']
    :type: integer Unix timestamp
    :Scope: Display

    Placeholder, containing a default date.

    ..  code-block:: php

        'placeholder' => '2027-05-12',
        'nullable' => true,
        'mode' => 'useOrOverridePlaceholder',

    ..  note::
        As the TCA is cached it is not possible to set dynamic values such as
        :php:`now()`.
