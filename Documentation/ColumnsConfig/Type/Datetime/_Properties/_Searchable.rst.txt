..  confval:: searchable
    :name: datetime-searchable
    :TCA path: $GLOBALS['TCA'][$table]['columns'][$field]['config']['searchable']
    :type: boolean
    :Scope: Display
    :default: `true`

    ..  versionadded:: 14.0
        TYPO3 now automatically includes all fields of suitable types in
        backend search operations in the :guilabel:`Content > Records` module.

        This option can be used to explicitly exclude fields from being searchable,
        instead of having to list them in the now removed option
        `$GLOBALS['TCA'][$table]['ctrl']['searchFields'] <https://docs.typo3.org/permalink/t3tca:confval-ctrl-searchfields>`_.

    By default, fields of type `datetime` are considered searchable unless they
    use a custom `dbType  <https://docs.typo3.org/permalink/t3tca:confval-datetime-dbtype>`_.

    To exclude a field from being searchable, set the following in the
    field's TCA configuration:

    ..  code-block:: php
        :caption: EXT:my_extension/Configuration/TCA/Overrides/tx_myextension_mytable.php

        $GLOBALS['TCA']['tx_myextension_mytable']['columns']['my_field'] = [
            'label' => 'My field',
            'config' => [
                'type' => 'datetime',
                'searchable' => false,
            ],
        ];
