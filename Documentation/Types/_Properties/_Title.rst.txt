..  confval:: title
    :name: types-title
    :TCA path: $GLOBALS['TCA'][$table]['types'][$recordType]['title']
    :type: plain text label or `label reference <https://docs.typo3.org/permalink/t3coreapi:label-reference>`_
    :Scope: Display

    ..  versionadded:: 14.0
        :changelog: feature-108027-1762779249

        It is now possible to define a type-specific `title` in the TCA `types`
        section.

    The `title` in the TCA `types` section defines a type specific title that
    is displayed in the backend when creating or editing a record of that type.

    The value is also available in the **Schema API**
    (:php:`\TYPO3\CMS\Core\Schema\TcaSchemaFactory`),
    making type-specific titles available when using :php:`$schema->getTitle()`
    and in the **FormEngine**
    (:php-short:`\TYPO3\CMS\Backend\Form\FormDataProvider\TcaTypesCtrlOverrides`
    data provider).
