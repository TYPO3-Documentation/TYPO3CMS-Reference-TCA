..  confval:: creationOptions
    :name: types-creationOptions
    :TCA path: $GLOBALS['TCA'][$table]['types'][$type]['creationOptions']
    :type: list of options

    ..  confval:: defaultValues
        :name: types-creationOptions-defaultValues
        :TCA path: $GLOBALS['TCA'][$table]['types'][$type]['creationOptions']['defaultValues']
        :type: array
        :Examples: :ref:`the example that creates the blog plugin at once <types-example-creation-option>`

        Default values inserted into the fields of the `tt_content` record on
        creation via the "New Content Element" wizard

        Can be overridden with page TSconfig option
        :confval:`tt_content_defValues <t3tsref:mod-wizards-newcontentelement-wizarditems-group-elements-name-tt-content-defvalues>`.

    ..  confval:: enableDirectRecordTypeCreation
        :name: types-creationOptions-enableDirectRecordTypeCreation
        :TCA path: $GLOBALS['TCA'][$table]['types'][$type]['creationOptions']['enableDirectRecordTypeCreation']
        :type: bool
        :default: true
        :added: 14.0

        Record types registered via TCA are automatically displayed in the
        "Create new record" component in the backend module
        :guilabel:`Content > Records`.

        A record type can be removed from that component. The type of a
        partnership comes from the partner conference, so the component shows
        no link for the types of a partnership:

        ..  literalinclude:: /CodeSnippets/my_extension/Configuration/TCA/Overrides/910-tx_myextension_partnership-type.php
            :caption: EXT:my_extension/Configuration/TCA/Overrides/910-tx_myextension_partnership-type.php
            :emphasize-lines: 33-34

        Event :php:`\TYPO3\CMS\Backend\Controller\Event\ModifyNewRecordCreationLinksEvent`
        can be used for more sophisticated modification of the dialogue.

    ..  confval:: saveAndClose
        :name: types-creationOptions-saveAndClose
        :TCA path: $GLOBALS['TCA'][$table]['types'][$type]['creationOptions']['saveAndClose']
        :type: bool
        :default: false
        :Examples: :ref:`the example that creates the blog plugin at once <types-example-creation-option>`

        If true, clicking on the new element wizard will take the user directly
        to the :guilabel:`Content > Layout` module, rather than showing the
        edit form from the form engine.

        Can be overridden with page TSconfig option
        :confval:`saveAndClose <t3tsref:mod-wizards-newcontentelement-wizarditems-group-elements-name-saveandclose>`.

    ..  confval:: title
        :name: types-creationOptions-title
        :TCA path: $GLOBALS['TCA'][$table]['types'][$type]['creationOptions']['title']
        :type: string | language reference
        :added: 14.0

        The title of the content element in the "New content element" wizard.
        By default, the wizard shows the label of the item in the field
        `CType`. This option only takes effect in the table `tt_content`. The
        "Create new record" component takes the label of a record type from
        :confval:`types-title`.

        A site package can give a content element of an extension another
        title in the wizard:
