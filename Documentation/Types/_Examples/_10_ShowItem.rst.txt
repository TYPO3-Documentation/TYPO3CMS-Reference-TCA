Group fields using tabs and use palettes
----------------------------------------

If a table has a larger number of fields, grouping them into tabs and palettes
can improves the backend user experience. Palettes have the additional value
that they can be reused across different record types.

The conferences have many fields in several tabs. The fields of the tabs are
added in the overrides of the extension:

..  figure:: /Images/Conference/CtrlDescriptionColumn.png
    :alt: The tabs of a conference
    :class: with-shadow

    The tabs of a conference

..  literalinclude:: /CodeSnippets/my_extension/Configuration/TCA/tx_myextension_conference.php
    :caption: EXT:my_extension/Configuration/TCA/tx_myextension_conference.php
    :visible-lines: 57-82
    :emphasize-lines: 61-69, 75, 79

The syntax for tabs is:

`--div--;<label>`

Where label can be plain text label or `label reference <https://docs.typo3.org/permalink/t3coreapi:label-reference>`_ (preferred).

The syntax to insert a palette is:

`--palette--;<label>;<paletteName>`

The label can be omitted.
