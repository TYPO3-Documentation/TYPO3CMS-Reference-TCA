PreviewRenderer examples
------------------------

..  deprecated:: 13.4
    Registration of subtypes has been deprecated.  Registration of custom
    types should therefore always be done by using
    :confval:`record types <ctrl-type>`.

    If you used PreviewRenderer with a subtype see section
    :ref:`Migration: PreviewRenderer for subtypes <migration-subtype-previewrenderer>`.

Demonstrates property: :confval:`types-previewRenderer`.

This specifies the preview renderer only for records with the record type `myextension_bloglist`
as determined by the field `CType` of the table `tt_content`.

This could be used to preview the blog plugin in the page module.

..  code-block:: php

    $GLOBALS['TCA']['tt_content']['types']['myextension_bloglist']['previewRenderer']
        = \MyVendor\MyExtension\Preview\PreviewRenderer::class;
