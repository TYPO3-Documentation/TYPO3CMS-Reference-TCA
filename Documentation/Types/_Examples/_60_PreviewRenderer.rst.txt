PreviewRenderer examples
------------------------

Demonstrates property: :confval:`types-previewRenderer`.

This specifies the preview renderer only for records with the record type
`myextension_conferencelist` as determined by the field `CType` of the
table `tt_content`.

This could be used to preview the conference list plugin in the
:guilabel:`Content > Layout` module.

..  code-block:: php

    $GLOBALS['TCA']['tt_content']['types']['myextension_conferencelist']['previewRenderer']
        = \MyVendor\MyExtension\Preview\ConferenceListPreviewRenderer::class;
